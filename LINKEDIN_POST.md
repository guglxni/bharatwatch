🚀 Built BharatWatch for the WeMakeDevs × Bright Data "Into the Scrape-Verse" hackathon!

It's a self-healing local intelligence layer for Indian public data — government jobs, tenders, mandi prices, college cutoffs, and startup schemes.

The hard part of civic scraping isn't extraction once. It's keeping the scraper alive when the site quietly changes its layout next week.

BharatWatch solves that with Bright Data Scraper Studio:
1. Custom collectors built with `npx @brightdata/cli scraper create`
2. Schema validation + diff engine
3. Natural-language `bdata scraper heal` when a layout breaks
4. Same collector ID, same API, no downstream code changes

I built 5 modules, verified 4 live collectors, and packaged it all in a clean Next.js dashboard + FastAPI backend.

Check the repo: https://github.com/guglxni/bharatwatch

Huge thanks to @wemakedevs and Bright Data for the hackathon and the credits.
